# Ownership statement

## Original work in this repository
All files under `src/`, `tests/`, `scripts/`, `launcher/`, `configs/`, `.github/`, `docs/` and `data/` were written for this assignment by an AI assistant (Claude Sonnet 5.5, via Claude Code) working from the candidate's requirements, across sessions on 2026-10-31 and 2026-11-01 (see `docs/ai_use_log.md`).
The numerical methods are standard textbook methods (linear finite elements, Thomas algorithm, central finite differences, chain rule) implemented from their definitions; no source code was copied from other projects.
